# مدار — منصة الموارد البشرية الداخلية

واجهة عربية RTL مع قاعدة SQLite محلية دائمة. تتطلب Node.js 24 أو أحدث، ولا تتطلب حزماً خارجية.

## التشغيل

```sh
cd /workspace/HR
npm start
```

المنفذ الافتراضي 3000، ويمكن تغييره عبر `PORT`. افتح التطبيق وأنشئ حساب المدير الأول بكلمة مرور لا تقل عن 12 حرفاً. لا توجد حسابات أو بيانات تجريبية افتراضية. يجب إكمال إعداد المدير على شبكة موثوقة قبل إتاحة الخادم للآخرين.

## الوظائف

- دليل الموظفين، الأقسام، المسميات، الرواتب الأساسية والبحث.
- تسجيل الحضور والانصراف وتحديث سجل الموظف في اليوم نفسه.
- طلبات إجازات مع قبول أو رفض المدير.
- مسيرات شهرية أولية بالراتب الأساسي تمنع تكرار الموظف في الشهر نفسه.
- لوحة مؤشرات، تقرير قابل للطباعة وتصدير دليل الموظفين بصيغة CSV.
- حساب مدير، جلسات بملفات ارتباط HttpOnly وSameSite، وتجزئة كلمات المرور بـ scrypt وحد لمحاولات الدخول.

## التحقق

```sh
npm test
```

اختبار تكامل ينفذ إنشاء المدير وتسجيل الدخول والموظف والحضور والإجازة والمراجعة والمسير والتحقق من منع التكرار وتسجيل الخروج. يتطلب السماح بفتح منفذ محلي.

## التخزين والنشر

تُحفظ البيانات في `data/hr.sqlite` (مستبعدة من Git). يمكن تحديد مجلد دائم عبر `DATA_DIR`. احتفظ بنسخ احتياطية آمنة باستخدام SQLite backup API أو بعد إيقاف الخادم ونسخ مجلد البيانات كاملاً. للنشر استخدم HTTPS خلف reverse proxy واضبط `SECURE_COOKIE=1`، ولا تعرض المنفذ مباشرة للإنترنت. لا تحذف مجلد البيانات عند التحديث.

## حدود الإصدار الحالي

هذا إصدار أولي تشغيلي للمنصة الداخلية. الصلاحية المتاحة هي المدير؛ بوابة الموظف والأدوار المتعددة ليست منفذة. المسيرات مسودات ولا تشمل الضرائب والتأمينات والاستقطاعات والقواعد القانونية أو التحويلات البنكية. لا يتضمن تكامل أجهزة البصمة أو البريد أو سجل تدقيق أو نسخاً احتياطية آلية. يجب مراجعة متطلبات المؤسسة والأمان والقواعد المالية قبل الاستخدام الإنتاجي.
